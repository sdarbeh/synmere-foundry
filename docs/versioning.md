# Avatar asset versioning

- **Patch**: safety, inversion, degeneracy, or validation repair with no
  intended visual or runtime-contract change.
- **Minor**: backward-compatible morphs, materials, capabilities, or manifest
  fields.
- **Major**: removed/renamed morphs, incompatible topology or material
  contracts, renderer contract changes, or manifest schema breaks.

The current pre-live production baseline is `1.0.0`.
